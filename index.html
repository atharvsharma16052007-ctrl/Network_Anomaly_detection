COMPREHENSIVE CYBER ATTACK TYPES REFERENCE MANUAL
This reference guide outlines cybersecurity attack categories, intrusion vectors, and telemetry anomaly patterns identified by Netshield. Upload external security logs or network captures matching any standard format to detect and flag these attacks.
Network Connection & Protocol Attack Vectors
DoS (Denial of Service)
Overwhelms a target system with excessive packet floods or malformed requests to make services unavailable.
Common Variants: SYN Flood, Smurf, Ping of Death, Teardrop, Land Attack
R2L (Remote to Local Exploits)
Unauthorized infiltration from external networks to local machines by exploiting misconfigurations or brute-forcing credentials.
Common Variants: Password Guessing, FTP Exploit, IMAP Abuse, Unauthorized Remote Shell
Probe & Reconnaissance
Systematic scanning to discover open services, network topology, firewall rules, and active operating systems.
Common Variants: IP Sweep, Port Sweep, Stealth Nmap, Satan Scan
U2R (User to Root Privilege Escalation)
Internal exploit where an authenticated standard account gains administrative or superuser privileges.
Common Variants: Buffer Overflow, Rootkit Injection, Perl Payload, Kernel Module Exploitation
Volumetric & Flow Infrastructure Attack Vectors
DDoS Attacks
Distributed Denial of Service flooding high-volume flow surges from geographically dispersed endpoints.
Brute Force Infiltration
Repeated rapid authentication requests over SSH, RDP, or HTTP attempting credential compromise.
Web Application Attacks
Cross-site scripting (XSS), SQL injection, and path traversal targeting backend application servers.
Port Scanning
Systematic automated probing across high-range destination ports to identify vulnerable listening daemons.
Botnet Activity
Coordinated communication channels between command-and-control (C2) servers and zombie endpoints.
Cryptographic Vulnerabilities
Exploitation of TLS/SSL flaws (e.g. Heartbleed) to leak private server memory and encryption keys.
Enterprise Threat Vectors & Security Breaches
Malware
Malicious software including viruses, trojans, worms, and spyware designed to damage or exploit systems.
Phishing
Social engineering attack using fraudulent emails or websites to steal credentials.
Ransomware
Encrypts victim data and demands payment for decryption keys.
Man-in-the-Middle
Intercepting communication between two parties to eavesdrop or alter data.
SQL Injection
Inserts malicious SQL statements to manipulate or extract database information.
Zero-Day Exploit
Attacks targeting previously unknown vulnerabilities before patches are available.
